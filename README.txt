GROWTH LEVEL — Learning & Career Dashboard

Files
- index.html: standalone website; no build tools required.

What's included
- Full daily time map in IST with start/end times, breaks, activity instructions, and measurable outputs.
- Existing 30-day subject-by-subject curriculum, daily checklist, progress score/levels, history, and local browser storage.
- Free-first resource library covering Class 6 mathematics, Java, coding/DSA, English communication, typing, Git/GitHub, SQL, projects, science, world affairs, math research, and sports.
- Searchable resources; some platforms have optional paid features, explicitly identified where known. This plan does not require paid subscriptions.
- Live-news RSS fetch attempt and links to primary news sources. RSS proxy or source access may be unavailable/rate-limited; the static site cannot guarantee live feeds.
- Built-in quiz, focus timer, browser reminders, and JSON export/import.

Important limits
- Progress is stored in this browser unless exported; it does not automatically sync between devices.
- Reminders and midnight backup need the page open and the computer awake.
- The midnight feature downloads a JSON file; it does not email it. Email requires a separately configured backend or automation service.
- The site was syntax-checked with Node.js, but has not received full end-to-end browser testing.

Publish with GitHub Pages
1. Extract the ZIP.
2. Upload index.html to the root of the desired GitHub repository and commit.
3. Repository Settings > Pages > Build and deployment: Deploy from a branch; choose the default branch and /(root); Save.
4. Wait for deployment, then open the published Pages URL shown by GitHub.
